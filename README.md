Token Radar ranks 300 pre-token protocols by an implied value computed from TVL, seven-day growth, age with no token and chain breadth, and gives each one a farm plan with concrete steps, costs and times.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
